# Catatan pemasangan OWASP WSTG Assessment

Modul Assessments telah diintegrasikan dengan aset, temuan, tiket, dan laporan SATRIA.

Alamat server, rute SSH/jump host, identitas akun, lokasi backup operasional, dan kredensial tidak dicantumkan dalam dokumentasi ini. Operator memperoleh konfigurasi akses dari pengelola lingkungan melalui penyimpanan internal yang sesuai.

Pembaruan mencakup checklist WSTG, evidence gambar, CVSS 4.0, Rules of Engagement (RoE), serta tampilan yang mengikuti template SATRIA.

Validasi mencakup alur assessment dan temuan, pembaruan RoE, penyimpanan evidence, autentikasi, dan perbandingan 4.096 vector CVSS dengan engine FIRST. Cadangan dibuat sebelum pemasangan; data existing dipertahankan.

Panduan umum instalasi dan rollback tersedia di [Operasional Assessments](assessments.md).
